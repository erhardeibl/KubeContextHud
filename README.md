# Kubernetes Context HUD

A draggable, always-on-top overlay that shows the active Kubernetes context and lets
you switch it.

## Running

```
python kubectx_hud.py
```

Needs Python 3.10+ with Tkinter, and `kubectl` on `PATH`.

Settings live in `config.json` next to the script.
